# Discovery redesign direction

Mode: Operate. Target: src/ui/discovery.rs, Home discovery only.
Serge rejected the prior interface and requested Opus 5.5 high-reasoning design,
error fixes, more discovery controls and recommendations without a fresh prompt.
He selected a working native interface first on October 6, 2026.

## Direction contract

THESIS: open on playable personal music, with curation and feedback one gesture
away; the prompt and unresolved suggestions no longer dominate Home.

OWN-WORLD: a native personal radio desk, quiet mountain scenery beneath a
flat forest/mist chrome plate, clear neutral text, compact 56-point rows and one moss
play action. Light/dark follow the desktop setting; no continuous blur or shimmer.

STORY: listen immediately, select Familiar/Balanced/Adventurous, signal more/less,
and let saved taste guide the next automatic refresh. One honest catalogue status
and retry explain partial results without filling the list with repeated errors.

FIRST VIEWPORT: a 26-point For you heading and play/refresh controls, a compact
exploration strip, a single summary, then 56-point playable rows with cover,
artist, duration, a bounded reason and two feedback icons. Taste editing opens
inline on request; unmatched suggestions and history begin collapsed.

FORM: candidate 5, personal radio desk, direction seed 0f7cc59f. The user's
requested native glass and Opus's concrete direction constrain the material.
The seven grounded forms were native library queue, record crate, mixtape sleeve,
listening journal, personal radio desk, DJ set list and editorial discovery feed.
Challengers contribute compact density and isolated destructive actions (console),
consistent alignment (dance notation), disciplined whitespace (record sleeve),
clear active controls (guide map), a reliable grid (type specimen) and efficient
bounded rendering (data field). Decorative systems that obscure native listening
controls were declined on task clarity and audience fit.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
